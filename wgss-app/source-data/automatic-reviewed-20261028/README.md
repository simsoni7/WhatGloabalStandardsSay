# 자동 검수 후 게시된 자료

2026-10-28 한국시간 기준 공개 API에서 저장한 자료입니다. 용어 208건과 화면 3건, 파생 문구·기능을 포함합니다.

`approved-records.json`에 영어·대상 언어 원문, 한국어 설명, 이용 조건, 원천 URL·해시, Bedrock 검수 기록을 보존합니다. `assets/`는 게시된 정확한 화면 이미지이며, `licenses/`는 해당 언어팩의 이용 조건 원문입니다. 금융사 이미지의 재사용 권리를 부여하는 자료는 아닙니다.

이 파일은 추가 게시 자료의 다운로드 스냅샷입니다. 실제 서비스는 기본 카탈로그와 실시간 승인 자료를 함께 읽습니다. 운영 로그·미승인 제안·비밀정보는 포함하지 않습니다.
