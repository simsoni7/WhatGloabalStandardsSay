# 2026-11-03 추가 게시 자료

용어 224건, Kraken 화면 1건 및 파생 문구 6건의 공개 API 스냅샷입니다. 기존 수집 대기열을 복구한 자료와 새 수집 자료를 함께 포함합니다. 추가 언어는 아제르바이잔어·구자라트어·마라티어·싱할라어·타밀어·튀르키예어·우크라이나어입니다. Mifos Web App 자료 50쌍을 포함합니다.

`approved-records.json`에 원문·대상 표현·한국어 설명, 원천 URL·해시, 이용 조건 및 독립 Bedrock 검수 근거를 보존했습니다. `assets/`는 게시 이미지 원본, `licenses/`는 이용 조건 원문입니다. `mifos-originals.tar.gz`에는 수정하지 않은 영어·한국어·아제르바이잔어·리투아니아어 JSON 원문과 MPL-2.0 LICENSE가 있습니다. 각 원문의 이용 조건을 유지합니다. 금융사 화면의 별도 재사용 권리를 부여하지 않습니다.

기존 카탈로그와 다른 날짜의 추가 자료 스냅샷을 합쳐 복원하며 같은 targetId는 최종 revision을 사용합니다. 실제 화면의 수치는 이후 승인·수집에 따라 변동됩니다. 운영 로그, 미승인 제안과 인증정보는 포함하지 않습니다.

`all-publications.json.gz`는 이 시점까지 승인한 전체 변경분을 담아 앞선 날짜 스냅샷 사이의 누락 없이 복원할 수 있습니다. gzip으로 풀면 공개 API와 같은 JSON입니다.
